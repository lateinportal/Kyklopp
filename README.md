# Kyklopp

Online-Testversion des Lateintrainers. Anmeldung mit persoenlichem Zugangscode; Lernstaende werden getrennt in Supabase gespeichert. Die a-Deklination sowie die o-Deklination auf -us/-(e)r und auf -um sowie die 3. Deklination (einschliesslich Mischstaemmen, ohne Neutra und reine i-Staemme) sowie Praesens (Indikativ Aktiv) und das eigene Thema zu esse/posse/velle/nolle sind nutzbar; weitere Grammatikuebungen sind noch in Vorbereitung.
